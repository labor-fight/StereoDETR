## 0. 动机与恒等式前提（物理组新读数，已核代码）

- `epipolar_features.py` 把 50 ms 全窗事件坍缩成单张 log1p 计数图再做 ZNCC——
  **C79 的 0.55 px（行人 20–30 m）已经是"未对齐全窗累积"的读数**。
  把窗切片后**不对齐**地平均剖面 ≈ 原图求和（恒等式），√N 论证在此没有分子。
- 时间维的真实余量 = **对齐增益**（去共模拖影展宽）+ 因果历史扩展，
  物理上界 ×1.8–3.5（【猜测】标注，从未实测）。
- C101 只否决了输出层恒速拟合；GT 深度区间内精确线性反而**保证**线性视差漂移
  模型在测量层是正确模型。F05/F06（表示层）、F17（陈旧 GT 锚定）均不被触碰。
- 极性通道在现提取器中完全未用（免费搭车项）。

## 2. 六臂设计（A 臂是控制格）

| 臂 | 定义 | 预注册预期 |
|---|---|---|
| A | 50 ms 全窗单图 ZNCC（现行为） | 必须复现 ~0.55 px（20–30 m 段），否则仪器无效 |
| B | 10×5 ms 切片、不对齐平均剖面 | ≈A（±10% 内）——恒等式的实测验证；B≪A 说明工具有 bug |
| C | 预测轨迹速度对齐后平均（GT-free：左目框中心轨迹斜率粗对齐 + 逐片自配准细对齐） | 主读数 |
| C′ | C + 因果历史扩展至 ≤145 ms（offset≥5 子帧可用） | 主读数 |
| D | GT 轨迹对齐（**仅诊断上界**，DIAGNOSTIC_FINDING，永不当可达值引用） | 上界 |
| N | 对齐向量跨对象置换 null | 不得改善（改善 → 对齐增益是伪影） |

搭车项（免费，同批产出）：极性分离双通道 ZNCC；行内（头/脚行）密度门控；
signed 误差对逐对象视差漂移回归（验证行人"表面-陈旧抵消"假说，斜率预期 ≈ +0.25–0.3，
直接校准 QC-EER δ 头的行人预期）。

## 3. 门（全部先冻结）

- **G-机制**：C/A ≤ 0.65 → 对齐增益机制成立；
- **G-扩门**：C′ 在 20–25 m 段中位 ≤ 0.18 px → 授权"OERD 门扩展到 ~25 m"
  单变量推理臂（zmax 20→25，其余门参不动，另行最小预注册）；
- **G-关闭**：C/A > 0.85 → 通道关闭，QC-EER 不加时间输入，ARM-TIME-M 取消，
  全项目最后一条未测时间通道就此落账（负结果同样入论文 §benchmark 结构分析）。
- N 臂改善 >5% → 对齐增益判 INVALID（F18 伪影纪律），C/C′ 读数作废。

## 6. 结果与裁决（2026-09-01 00:21 落账，n=300 train 行人，仪器锚复现通过）

| 距离段 | A 全窗分半 | B 无序切片平均 | C 对齐平均 | N null | C′ 145ms |
|---|---:|---:|---:|---:|---:|
| 15–20 m (n=97) | 0.352 | 0.329 | =B（配准全回退） | =B | 0.638 |
| 20–25 m (n=93) | 0.480 | **0.239** | =B（配准全回退） | =B | 0.613 |
| 25–30 m (n=110) | 0.386 | 0.423 | 0.445 | 0.462 | 0.510 |
| 20–30 m (n=203) | 0.407 | 0.319 | 0.342 | 0.336 | 0.559 |

**裁决 = INCONCLUSIVE_BAND（C/A=0.84 ∈ (0.65, 0.85]），且机制层解读为负**：
5 ms 切片在 25 m 内稀疏到配准整体回退（B=C=N 逐位相同），对齐机制真正接上的
25–30 m 段反而更差（0.445 > 0.423）且 ≈ null——**轨迹相干对齐在此 SNR 下不是杠杆**
（物理组反对意见 1 的预测成真）。C′ 145 ms 全段恶化，因果扩展关闭。
G-extend 未过（0.613 ≫ 0.18），OERD 25 m 扩门**不授权**。N 守卫通过（无伪影）。

**未预注册的正发现（report-only，不得直接当增益引用）**：B 臂（无序切片剖面平均，
置换不变）在 20–25 m 把分半重复性砍半（0.480→0.239 px，σ≈0.17 px ≈ 22.5 m 处容差
0.168 px）——鲁棒统计增益（逐片归一化压制爆发噪声），与时间戳顺序无关，
**不能承载 4D 主张**，但构成 OERD 提取器 v2（切片平均剖面）的立项动机。

**路由（按纪律）**：
1. ARM-TIME-M（QC-EER-T）期望值下调：其 T-D0 的"方差主导"前提在 25 m 内不可测
   （配准不可用），4D 主张按预案退向任务契约承载（ARM_TIME 预注册 §3 退路 A）；
   本轮不再为测量层时间机制占任何臂位。
2. 新立项候选 **OERD-EXT-B**（另行最小预注册）：提取器聚合模式改为切片平均剖面，
   唯一变量，冻结门参不动（z≤20 m），门 = 冻结箱集上行人 gated 深度中位改善 ≥10%
   且 null 不变；20→25 m 扩门只能在该臂 PASS 后以第二个预注册进行。
3. 本探针的对齐实现（整数 FFT 配准）若要复审需 v2 亚像素配准 + 更长切片（10 ms），
   属新预注册；本轮不做。
