## C76 | METRIC_DEFECT | 立体对应探针的真值必须用角点视差带，不得用中心视差

**现象**：D2 记录 truth-beats-wrong 0.3590（below chance），且呈"近处更差
（0-10m 0.229 vs >30m 0.421）、大 patch 更差（>50px 0.252 vs <25px 0.481）"
的反直觉相关。

**根因**：立体匹配发生在物体**可见表面**，而探针以 box **几何中心**的
fB/Z 作为真值视差。两者相差 ≈ fB·(l/2)/Z²：569×0.599 的标定下，10m 处
车差 8px+、25m 处差 1.4px。该偏差恰好制造全部三个反直觉模式。独立重写
的审计装置证明：换 8 角点表面带判据后 train 0.414→0.631、0-10m 桶
0.000→0.778，深度趋势反转为物理正常（近好远差）；车的隐含表面偏移中值
2.18m ≈ 真实车半长（机制指纹）。

**规则**：任何立体对应性探针（1）真值一律取 8 角点投影视差区间
[fB/z_far_corner, fB/z_near_corner]±容差；（2）必须附合成正控制
（自体平移，C73）并报告控制通过率；（3）必须分深度桶报告；（4）控制
失败的 patch 子集不得计入结论（本次 val `zurich_city_08_a_02` 左缘
截断 patch 先例）。

## C77 | MECHANISM_CONFIRMED | 三个修复靶点的零训练验证

1. **L2 打分塌缩可修且预算明确**（R1 归档 C2_BOTTLENECK.json）：行人
   2D IoU≥0.10 查询覆盖 94.3%；score-IoU Spearman 0.098；紧覆盖行人
   GT 的最佳预测中位分 0.0126 低于解码阈值 0.1；oracle 重排序
   Veh 6.26→11.39（超 EvStereo3D checkpoint 8.02）、Ped 0.19→1.87。
   → 车的超越预算完全在打分/排序内；行人打分修复上限 ~1.87，其余
   必须来自框质量/泛化改善。
2. **SEIT 立体一致事件实例移植物理有效**（run4-fix，双次逐字节一致）：
   事件级提取→视差/尺寸重缩放→跨场景粘贴后，移植行人的表面带命中率
   T1 位置 10/10、T2 变远 12/12、T2 变近 9/12，不低于真实行人基准
   （train 0.667 / val 0.778）；T0 恒等移植控制 4/4。
3. **跨窗查询传播先验强**（3,359 相邻帧对）：50ms 窗口间运动中值
   车 2.95px / 行人 3.42px，P90 ≈ 10px。
