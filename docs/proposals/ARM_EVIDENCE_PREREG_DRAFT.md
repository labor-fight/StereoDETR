## 1. 装置

1. `model.qc_eer.enabled`(默认 false,旧臂逐位不变)。输入:左右视图 backbone
   高分辨率特征(或事件计数/时间面通道);对每个匹配预算内的 query,在其候选框
   2D 投影带与视差假设区间 [z−3m, z+3m]∩[2m, 20m](类门:行人 20 m,车辆冻结为
   全程但偏移头必过 G3 才准在推理开启)内做逐视差假设相关剖面。
2. **头**:剖面 + query 特征 → (a) Δz 残差(相对解码深度);(b) 表面→中心偏移
   δ(class, sinα, cosα, l̂);(c) 证据标量 e(峰锐度/带命中,供 sq_rank 融合,
   若 ARM-SCORE 未过则 e 不接入)。最终深度 = decode_z + Δz + δ,σ 同步重估。
3. **损失**:匹配 query 的深度 L1(目标 = Q13 时间对齐后的 GT z,类分母全组平均);
   证据标量无独立损失(只作特征)。
4. **推理消融行(同 checkpoint)**:关模块 / 只 Δz / Δz+δ / 零参数 OERD(oerd_apply
   同门参)——学习版必须打赢固定门参版,否则无存在理由。

## 2. 单变量对照与门

- 基座 = ARM-SCORE 裁决后的胜者配方(含或不含 sq_rank 以胜者为准);唯一 diff =
  `qc_eer.enabled: true`。12 epoch 侦察,e006/e009/e012,主门 = e009/e012 均值(F29)。
- **G1(行人深度)**:gated 行人深度中位(0–10 m 段)≤ 0.065 m(零参数 OERD 同框
  参考 0.058 m,容差半个噪声位)。
- **G2(行人主门)**:Ped strict 均值 ≥ "基座 + 零参数 OERD 推理组件"的组合读数
  (学习版必须不差于免费版,这是本臂的存在性门)。
- **G3(车辆守卫)**:Veh strict ≥ 对照 ×0.95;且车辆侧 val 偏移后系统偏差
  |median(ẑ−z_gt)| ≤ 0.5 m,否则**车辆侧推理自动关闭**(行人侧独立保留,Z5b 先例)。
- **G4(机制破坏,E3 纪律)**:右目输入置换(计数匹配供体)后增益移除 ≥50%。
  时间戳块打乱作报告项:若增益不依赖时间戳,本臂不承载时间主张(时间主张归 ARM-TIME)。
- **Kill**:G2 两点均值失败 → 删学习版,零参数 OERD 保留为推理组件;G4 失败 →
  证据通道主张作废,不得靠加大容量抢救(F08 教训)。

## 3. 不做什么

- 不建全图 plane-sweep/代价体(反相似红线,台账 §16);不复活 wireframe(F08);
- 不做车辆深度整体替换(Z5b 终审关闭;本臂车辆侧只做"残差+条件偏移",且有 G3 闸);
- 不用 GT 或私有字段构带(带由预测框构造,同 Z1 无泄漏纪律);
- 不与 ARM-SCORE 同臂合跑(A3 联合臂教训:归因失败即全废)。
