## 3. 取胜臂序列与完整决策树（最重要交付）

### 3.0 先装一个仪器：k̂ 读数（零 GPU，必须在 e006 之前就位）

**问题**：Q12 的 H2/H3 是 AP 门、H4 是非回归门，**它们回答不了"我离赢还有多远"**。C117 已确立"AP 缺口百分比不是难度度量"，而**已标定的仪器是收缩面**。

**仪器 I1 — k̂ 读数**。每个 dump 出的 checkpoint 上：`tools/q2_scoring/common_population_fields.py`（固定与 a2 控制组的共同真值群体，按真值对象建键取交集）+ `tools/q2_scoring/field_error_magnitudes.py`（同一 2D IoU 0.3 关联门 + `in_model_view`）。输出每类每字段的**中位与 p90**，令
`k̂_depth = arm_median / control_median`（同一群体内；**比值可跨工具引用，绝对值不可**，C105），再查 §0 第 2 条的表得到"若该 k̂ 是按比例达成的，AP 应该是多少"。

**目标线：Veh 8.0215 → k̂ ≤ 0.470；Ped 3.6448 → k̂ ≤ 0.436。统一 k̂ ≤ 0.43。**

对应绝对目标（**每个数字必须复述它的群体门**）：

| 类 | 群体 | 控制中位 | k̂=0.43 目标 |
|---|---|---:|---:|
| 行人 | 三臂共同真值群体（C119，n=588） | 0.2043 m | **0.0879 m** |
| 行人 | 2D IoU 0.3 + in_model_view（n=1028 det / 897 truth） | 0.23875 m | **0.1027 m** |
| 车 | 共同真值群体（C120，n=9449） | 0.3288 m | **0.1414 m** |
| 车 | 2D IoU 0.3 + in_model_view | 0.42788 m | **0.1840 m** |

**本报告唯一新增的预注册项，现在（任何 AP 数字出现前）冻结：**

> **I1-门（观察项，非淘汰性）**：在 e006/e012/e018/e024/e030/e036 每个 checkpoint 报告 k̂_depth（两类、两群体、中位与 p90）与 k̂_shape。
> **I1-路由（淘汰性）**：若 **e024** 时 k̂_depth(行人, 共同群体) **> 0.90**，判定"噪声削减族（退火/更长训练/权重平均/集成）在本模型上对深度无效"，**禁止再启动任何调度类或平均类臂**，窗口路由到信息增加类臂（Arm D）或 EpiTube4D。

**为什么这条门值钱**：C99 测出深度误差方差有 **96.1%（车）/ 95.9%（行人）** 落在不可解释项 `Var(u)` 里，所以噪声类干预的理论天花板是 **0.197×**——远优于 0.43 的需求。但 C99 自承这是**上界不是预测**（`u` 里混着可削的权重抖动与不可削的特征驱动系统误差，静态分析分不开）。**I1 在 e024 用 17.5 小时把这个二选一实测掉。这是整个 72h 里信息量最高的一次读数，且免费。**

**仪器 I2 — 按类后验重打分**（`tools/q2_scoring/rescore_study.py`，`image_id % 2` 两折交叉拟合，只对行人）。零 GPU，每 checkpoint 跑，作为**组件**登记（C17/C21），score-only 与 end-to-end 分开报。

**仪器 I3 — C118 检查单**：每个新臂开跑前打印它与**被对标 checkpoint 的训练配置**的逐键差集（不是与配置文件的差集）。当前基准 `q12_seit_long36.yaml` 相对 `a2_seit.yaml` 的**完整**差集：

## 4. 审稿人视角

### 4.1 先承认真相，再选战场

`EP4D_SOTA_10_Plans` §13.1 的防守策略是"用 architecture trace 证明我们没有 plane sweep / voxel / BEV / anchor / ROI"。**这在当前状态下是自杀**：我们没有重写架构（重写路线已被 §1 全数判死），所以我们**确实**与 EvStereo3D 同代同族。论证架构差异等于用一个数字更差的新架构去防守，审稿人会同时打掉新颖性和有效性。

**正确动作是把架构从贡献里拿掉。** 骨干、事件体素化、DETR 解码器、稠密立体相关全部承认为 prior work，明写"我们与 EvStereo3D 共享测量前端"。贡献放在三个它没有、也不容易做的地方。

### 4.2 三条可防守的贡献

**贡献 1（最强）：一套已标定的 3D 检测误差预算可达面 + 两个指标反号反例**

核心不是"我们做了消融"，而是**这个仪器自带精确控制格、它救过我们、而且它推翻了文献里的通行做法**：

- 算子是"把模型自身误差按比例收缩到真值"：`field = truth + k·(pred − truth)`，保留误差的**形状**与**字段间相关性**。`k = 1` 的格子**逐位复现**冻结基线（8.2400 / 19.3645 / 32.6882 / 2.1715 / 3.0048 / 7.7430），且 k = 0.25 与 0.40 在两份独立生成的收据里四位小数一致。
- 它替换掉的那个自然做法——"真值 + 中位数匹配的独立高斯噪声"——在同一个控制格上给出 Veh R11 **0.6912** 对真实 **8.2400**，**差 12 倍**（C86）。原因是真实误差在字段间相关且形状比高斯更尖。**文献里大量"若把 X 做到 σ 就能拿多少 AP"的分析用的正是这个被证伪的算子。**
- 它产出四个反直觉、有收据、可复现的结论：
  1. **只改深度到 0.43× 就同时越过公开权重两类**（0.40× → Veh 8.5854 / Ped 4.0293），而"把深度做好"的天真**绝对**规格（σ≤0.10 m）在这套 f·B=349.5 的装置上不可表示——**比值规格可表示、绝对规格不可表示，两者不能互相搬运**（C111）。
  2. **单独把朝向做准会让车 AP 掉 30%**（0.50× → 3.5217），而在其他字段完美时朝向又值 6.9 分（`all_but_yaw` 44.1499 vs `all_3d` 51.0128）。**单字段改进的符号是条件于其他字段的。**
  3. **把尺寸头输出方差匹配到真值方差会让车 AP 掉 41%**（gain 1.30 → 2.9360），尽管解析上误差方差只降约 5%。**AP 吃尾部不吃方差。**
  4. **同一次干预可以让 R11 和 R40 反号。** 两个独立实例：`size_gain` 1.30 使 Veh **R11 8.2400 → 10.0294（+22%）** 而 **R40 5.0077 → 2.9360（−41%）**；blind-time offset 9 使 SEIT 的 Veh **R11 +43%** 而 **R40 只有 +4.5%**。R11 的 11 点插值网格 + 100/11 = 9.0909 地板在稀疏检测下会把两种截然不同的预测判成同一个数。**这不是纪律条款，是有收据的方法学结论，直接影响任何仍在报 AP11 的 3D 检测文献。**
- 审稿人问"这不就是消融吗"：不是。消融回答"这个模块有没有用"；可达面回答"**要把哪个量改到多少才够**"，并在实验开始前算出某些臂注定失败——本项目用它在**零算力**下杀掉了 Q4（省约 20 GPU·小时）。

**贡献 2：3D 尺寸回归的可观测性天花板（把"回归到均值"从优化病理改写为可观测性陈述）**

- 现象：车长预测对真值斜率 0.2373 / 相关 0.5903；行人长相关 **−0.0328**、行人高相关 **0.0180**——头在输出常数。文献通常归因于"L1 收敛到条件中位数""少数类欠训练""损失权重不够"。
- 我们逐条测掉这些解释：
  - 欠付梯度？`loss_dim` 只占加权梯度范数 1.36%，Q6 抬 12.3 倍到 11.27%（梯度审计确认落地），**斜率只从 0.2373 动到 0.2518**，两类 R40 反而退化。
  - 欠训练？训练器根本没有 LR 衰减路径（C91）；Q8 加退火后车长相关 0.5903 → 0.8376、斜率翻倍，但**中位绝对误差只降 4%**（C109）——头变得更敢响应，没有变得更准。
  - 那是什么？**交叉拟合的可观测性天花板**：用模型自己拥有的 (2D 框, 深度, 朝向) 做 5 折交叉拟合，车长天花板 corr 0.5669 / 中位 0.4036 m，**模型已在 0.5903 / 0.4224 m，headroom 1.047×**（车高 0.978×、车宽 1.052×，已达或已越过）。换真值输入天花板才升到 0.9090 / 0.2870 m（headroom 1.472×）。
  - 附赠两个更锋利的读数：**行人高度头比直接输出类均值差 14.8 倍**（模型中位 0.08288 m，常数预测器 0.005587 m）；同一字段相对 oracle 输入天花板的 headroom 是 **22.2×**——**行人高度是全表唯一一个"既远离天花板又远差于常数"的字段，即它现在是净负贡献。**
- 可防守陈述：**"3D 检测器的尺寸头塌缩，在这类系统里主要不是优化问题，而是它的输入（自身 2D 框与自身深度）本身不携带更多尺寸信息；因此改进尺寸的正确路径是改进上游的 2D 框与深度，而不是给尺寸头更多梯度或更强的损失。"** 可在任何检测器上用同样的 5 折交叉拟合复现，成本几分钟 CPU。

**贡献 3：盲时段协议观察 —— 必须重写，且必须自带反例**

⚠️ **原始卖点（"SEIT offset 9 的 11.79 vs 全帧 8.24 说明事件流在盲时段有优势"）站不住，必须放弃。** 补上对手行之后：**EvStereo3D 自己在 offset 9 的 Veh R40 增益是 +45.1%（8.0215 → 11.6354），我方 SEIT 只有 +4.5%（5.0090 → 5.2365）。** 我们引用的 +43% 是 R11。**若按原表述投稿，任何拿到公开 checkpoint 的审稿人一张表就能推翻，并且会顺带质疑我们全部的选择性报告。**

重写后**仍然成立**的部分：

1. **协议事实（最强，纯数据集性质）**：官方 val 视图是 1,140 interval × 10 sub-frame = 11,400 帧，其中只有 offset 0 与 RGB 曝光重合。**90.0% 的被评测帧发生在没有同步图像的时刻**，而**所有现有方法只报区间平均，从不按"距上一次曝光多远"分层**。我们给出全部 10 个 offset × 全部归档臂 × 两个指标的完整分层表——**包括对手**。
2. **图像监督结构性够不着盲时段**（EpiTube4D 实测）：intensity teacher 只覆盖 **11.3%** 的真实对象（26/26 manual 有 teacher，230 个 blind 里只有 3 个）。**这是一句有测量支撑、且与第 1 点独立的动机句。**
3. **唯一幸存的方向性差异在行人上**：offset 9 时 EvStereo3D 的 Ped R40 **−3.0%**（3.6448 → 3.5348）而 SEIT **+30.3%**（0.6686 → 0.8709）。**但基数极小，必须先做序列块 bootstrap CI**（零 GPU，§2.3 第 6 项，已排在 +0h）。**CI 跨 0 就整节删除。**
